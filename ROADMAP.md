# Development roadmap

## Phase 1: Foundation
- [ ] Scaffold Anchor, SDK and frontend; pin dependencies.
- [ ] Configure local validator and CI.
- [ ] Define account layouts and instruction interfaces.

## Phase 2: Protocol
- [ ] Create currency and isolated vault.
- [ ] Implement mint and redemption.
- [ ] Implement atomic conversion.
- [ ] Test reserve invariants, invalid accounts and rollback.

## Phase 3: Interface
- [ ] Wallet connection and creation form.
- [ ] Mint, redeem, transfer and conversion flows.
- [ ] Reserve dashboard and transaction feedback.

## Phase 4: Demo
- [ ] Deploy devnet with clearly labelled test collateral.
- [ ] Demonstrate two currencies, conversion and redemption.
- [ ] Verify reserves and CI checks; document setup.

## Later
SOL-backed issuance, bulk distribution, ordinary token creation, governance and audits.

Suggested workstreams: protocol, frontend, SDK/testing, product/demo. Team to assign owners.
