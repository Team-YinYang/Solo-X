# Currency discovery (#26)

Use the workspace discovery panel on devnet or a local validator. It enumerates program-owned 172-byte state candidates and independently validates the canonical state, discriminator, version, PDA bumps, configured collateral, mint authority, freeze policy, isolated vault and current reserve coverage. Full mint addresses are the identity; names and symbols are deliberately not displayed or trusted. Copy the address into mint, redeem or conversion forms. The shared account loader repeats validation before building transactions; the on-chain program remains the final authority. RPC errors fail closed; discovery is a point-in-time view, not a guarantee of future solvency or RPC honesty. Large deployments will need pagination/indexing. Run npm run test --workspace @solo-x/web and the normal workspace lint/typecheck/build. On devnet verify a valid currency appears and an unrelated mint is rejected. No production funds.
